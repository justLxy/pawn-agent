# AI 当铺人生

《AI 当铺人生》是一款模拟经营类文字网页游戏。玩家扮演一家当铺的老板，通过接待顾客、鉴定物品、讨价还价、修复商品、转卖获利和升级店铺，逐步发展自己的当铺事业。

与传统固定内容的经营游戏不同，本作的物品、顾客、对话、谈判、物品故事、鉴定过程、修复挑战和随机事件都由 AI 大模型实时生成。游戏目标是在保留《当铺人生》核心经济循环的基础上，让每一次交易都拥有新的叙事、风险和决策空间。

## 核心体验

- 纯文字驱动的沉浸式当铺经营体验。
- AI 生成无限物品，每件物品都有独特名称、历史、价值、损坏状态和潜在秘密。
- 自然语言讨价还价，玩家可以直接用文字说服、试探、压价或识破顾客。
- 动态顾客系统，每位顾客都有性格、背景、经济状况、心理价位和谈判底线。
- 鉴定、修复、展示、转卖构成完整的物品处理链路。
- 随机事件会影响资金、安全、声誉、市场价格和经营节奏。
- 技能、设施、员工、贷款和税收共同组成长期经营压力。
- AI 不可用时会使用本地模板兜底，保证离线或配置缺失时仍可完整游玩。
- UI 风格定位为现代暗黑奢华风与复古当铺质感融合，文字是主角，界面是氛围和引导。

## 游戏目标

玩家的长期目标是让一家普通当铺成长为高端、稳定、可信赖的交易场所。游戏不只考验单次交易中的压价能力，也考验玩家对现金流、风险、库存、修复成本、展示收益、员工配置和长期升级路线的判断。

玩家需要在以下目标之间做取舍：

- 保持足够现金流，应对租金、税收、维修和突发事件。
- 用低价收购高潜力物品，通过鉴定、修复和转卖扩大收益。
- 识别赝品、欺诈顾客和高风险交易。
- 提升当铺等级，吸引更高价值顾客和稀有物品。
- 投资设施和员工，降低长期成本并提高交易成功率。
- 管理声誉和顾客关系，为后续交易创造更好条件。

## 核心循环

游戏的基础循环围绕每日经营展开：

1. 顾客上门：系统生成当天顾客队列，AI 可用时优先生成顾客身份、物品和背景，失败时使用本地模板兜底。
2. 查看物品：玩家读取物品基础信息、外观描述、顾客说法和初步估价。
3. 鉴定判断：玩家可以直接凭经验判断，也可以花费时间或金钱进行专业鉴定。
4. 谈判报价：玩家与顾客就价格进行自然语言谈判，也可以使用明确报价。
5. 达成交易：交易成功后物品进入库存；谈判失败则顾客离开，可能影响声誉。
6. 处理物品：玩家决定直接出售、修复后出售、放入展示柜等待高价买家，或继续持有。
7. 结算经营：每日产生租金、水电、员工工资、税收、贷款利息等成本。
8. 升级扩张：玩家用利润升级设施、雇佣员工、提升技能和解锁新系统。

## 顾客系统

每位顾客由 AI 动态生成，顾客不是简单的买卖窗口，而是一次交易中的主要对手和叙事来源。

顾客生成输入可以包括：

- 顾客类型
- 性格倾向
- 经济状况
- 交易目的
- 是否急需现金
- 是否存在欺诈意图

AI 输出内容包括：

- 姓名、年龄和外貌描述
- 说话风格和情绪状态
- 背景故事
- 来当铺的原因
- 期望成交价
- 最低可接受价或心理底线
- 容易被说服的点
- 对风险、时间和现金的敏感程度
- 是否隐瞒物品缺陷或试图欺诈

常见顾客类型包括：

- 急需用钱者：更容易接受低价，但情绪波动较大。
- 收藏爱好者：了解物品价值，谈判更谨慎。
- 继承物品者：可能不清楚真实价值，也可能带有情感依恋。
- 职业倒卖者：熟悉市场，报价更强硬。
- 欺诈型顾客：可能伪造来源、隐瞒损坏或试图出售赝品。
- 名人或特殊访客：带来高价值物品、声誉机会或特殊事件。

## 自然语言谈判

谈判是游戏的核心交互。玩家可以用自然语言和顾客对话，而不是只点击固定选项。

谈判系统会将以下内容作为上下文：

- 当前游戏日期和当铺状态
- 顾客性格、背景和心理价位
- 物品信息、损坏程度和估价范围
- 当前报价
- 谈判历史
- 玩家技能等级
- 当铺声誉

AI 会根据上下文生成顾客回应，并判断玩家输入中的意图，例如：

- 报价
- 压价
- 质疑真伪
- 强调风险
- 表示同情
- 利用专业知识说服
- 威胁放弃交易
- 试探顾客底线

谈判策略类型：

- 强硬型：坚持高价，不容易让步，需要证据或强说服。
- 急切型：急于出售，更容易接受低价。
- 犹豫型：需要情绪安抚或价值解释才会交易。
- 欺诈型：试图以次充好，可能在被识破后改口、降价或离开。

谈判结果可能包括：

- 顾客接受报价
- 顾客提出反价
- 顾客情绪恶化
- 顾客透露更多物品信息
- 玩家识破欺诈
- 顾客离开
- 声誉变化
- 解锁后续事件

## 物品系统

物品由 AI 生成，既是经济资产，也是叙事载体。每件物品都应具备可交易价值、背景故事和不确定性。

物品生成输入可以包括：

- 物品类型
- 稀有度
- 年代
- 损坏程度
- 价值范围
- 来源背景
- 是否存在隐藏属性

AI 输出内容包括：

- 物品名称
- 详细外观描述
- 历史背景和故事
- 初步市场价值
- 真实价值
- 损坏情况
- 修复难度
- 鉴定要点
- 真伪判断线索
- 隐藏属性或特殊效果
- 潜在买家偏好

物品稀有度分为：

- 普通：常见物品，价格稳定，利润较低。
- 稀有：有一定收藏价值，适合鉴定和展示。
- 史诗：高价值、高风险，可能需要专业鉴定。
- 传奇：极其稀有，可能带来巨额利润、特殊事件或法律风险。

物品状态会影响价值：

- 完好：可直接转卖，风险较低。
- 轻微损坏：修复成本低，适合提高利润。
- 严重损坏：需要时间、金钱和修复技能。
- 可疑状态：可能存在赝品、违法来源或隐藏缺陷。

## 鉴定系统

鉴定用于揭示物品真实信息，降低交易风险，并可能发现隐藏价值。

玩家可以选择：

- 免费粗略判断：成本低，但准确性受鉴定技能影响。
- 专业鉴定：花费金钱或时间，得到更可靠结论。
- 特定方法鉴定：根据物品类型选择材质、年代、工艺、印记、来源等方向。

AI 会生成鉴定过程，包括：

- 鉴定步骤
- 观察到的细节
- 可疑之处
- 真伪判断
- 估价变化
- 隐藏故事
- 后续建议

鉴定结果可能是：

- 确认为真品，价值上升。
- 判断为赝品，价值下降。
- 发现隐藏历史，提升稀有度或售价。
- 发现损坏隐患，增加修复成本。
- 发现法律或来源风险，引发后续事件。

## 修复系统

损坏物品可以修复后出售，但修复需要成本、时间和技能判断。

修复过程由 AI 生成，包括：

- 损坏部位描述
- 修复方案
- 所需材料
- 所需时间
- 费用估算
- 修复风险
- 可能出现的意外

玩家可以选择不同修复策略：

- 低成本修复：花费少，但效果有限，可能影响售价。
- 标准修复：成本和收益平衡。
- 高级修复：费用高，但有机会显著提升价值。
- 暂不修复：保留现金流，直接转卖或等待更好时机。

修复结果可能包括：

- 修复成功，物品价值提升。
- 修复一般，价值小幅提升。
- 修复失败，物品进一步贬值。
- 意外发现隐藏结构、铭文、宝石或历史证据。
- 修复引发额外事件，例如专家关注、买家预约或法律纠纷。

## 经济系统

经济系统是经营压力的核心。玩家需要在现金流、库存、风险和长期投资之间保持平衡。

基础设定：

- 初始资金：$10,000
- 每日运营成本：租金、水电费、员工工资等。
- 市场价值波动：不同类型物品会受到市场趋势影响。
- 修复成本：损坏物品需要投入资金和时间。
- 鉴定成本：专业鉴定能揭示真实价值和隐藏故事。
- 贷款系统：玩家可以向银行贷款，但需要支付利息。
- 税收系统：定期缴纳营业税。

主要收入来源：

- 收购后转卖物品
- 修复后高价出售
- 展示柜吸引高价买家
- 特殊事件奖励
- 名人或收藏家委托

主要支出来源：

- 物品收购成本
- 鉴定费用
- 修复费用
- 每日运营成本
- 员工工资
- 贷款利息
- 税收
- 随机事件损失
- 设施升级费用

经营风险包括：

- 现金流断裂
- 高价买入赝品
- 修复失败
- 库存积压
- 市场价格下跌
- 被抢劫或诈骗
- 法律纠纷
- 税务压力

## 技能系统

技能影响玩家在核心循环中的成功率、成本和收益。

技能类型：

- 谈判技能：影响顾客让步幅度、压价成功率和谈判容错。
- 鉴定技能：影响免费鉴定准确性、可发现的信息深度和识破赝品概率。
- 修复技能：影响修复成本、修复成功率和最终品质。
- 魅力技能：影响顾客初始态度、信任度和愿意沟通的程度。
- 商业技能：影响运营成本、转卖售价、展示收益和市场判断。

技能提升可以来自：

- 成功交易
- 失败经验
- 特殊事件
- 设施升级
- 员工协助
- 长期经营成就

## 当铺升级系统

玩家可以将利润投入设施，改变经营效率和可触达内容。

升级方向：

- 展示柜升级：增加可展示物品数量，提高展示售价和高价买家出现概率。
- 安全系统升级：降低被抢劫概率和损失。
- 鉴定室升级：提高专业鉴定速度、质量和隐藏信息发现率。
- 修复工坊升级：降低修复成本，提高修复成功率和修复品质。
- 店面升级：吸引更多高价值顾客，提高当铺声誉。
- 员工雇佣：雇佣鉴定师、修复师、保安等员工。

员工类型：

- 鉴定师：提高鉴定准确性，降低鉴定时间。
- 修复师：提高修复效率，减少失败风险。
- 保安：降低抢劫损失，提高安全等级。
- 店员：改善接待效率，提升顾客满意度。
- 经理：降低部分运营成本，改善每日结算。

## 随机事件系统

随机事件让经营过程产生不可预测性。每日结算默认约六成概率触发事件，并带有连续安静天数保底，避免玩家长时间只做重复交易。事件会先生成本地结构化结果作为兜底；如果 AI 可用，后端会尝试用 AI 生成的事件替换本地事件，让描述、人物、地点、物件线索和选择后果更具变化。

AI 输出内容包括：

- 事件描述
- 触发原因
- 多个发展分支
- 玩家可选方案
- 每个选择的潜在后果
- 对资金、声誉、库存、安全或技能的影响

事件类型：

- 抢劫事件：考验安全系统和现金管理。
- 诈骗事件：考验鉴定能力和谈判判断。
- 名人来访：可能带来高价值交易或声誉提升。
- 稀有物品出现：提供高风险高回报机会。
- 市场波动：改变某类物品价格走势。
- 法律纠纷：涉及物品来源、税务或合同问题。
- 员工问题：员工失误、离职、涨薪或带来机会。
- 修复事故：影响修复成本、修复技能或物品后续处理。
- 鉴定线索：提供学习机会，也可能暴露来源风险。
- 银行授信：围绕贷款、利率和现金流产生经营选择。
- 老客介绍：通过顾客关系带来声誉、机会或额外成本。
- 天气影响：改变当日客流、营业成本或急售机会。
- 街坊传闻：带来短期市场情报或稀有物品线索。
- 收藏家邀约：要求玩家寻找或出售特定类型物品。
- 媒体曝光：提升客流，也可能放大负面事件。

离线兜底事件池包括夜间异响、可疑典当、名人来访、市场风向变化、来源质疑、员工小问题、巷口传闻、修复师来信、鉴定讲座、老客介绍、银行经理电话和暴雨压街。每个事件选项都通过结构化后果影响现金、声誉、技能经验或市场系数。

## 库存与展示

玩家收购的物品进入库存。库存不是单纯存储空间，而是资金占用和机会管理。

玩家可以对库存物品执行：

- 查看详情
- 再次鉴定
- 修复
- 直接出售
- 放入展示柜
- 保留等待市场上涨
- 用于特殊事件或任务

展示柜用于提高售价，但展示空间有限。玩家需要决定哪些物品值得占用展示位。

展示物品可能吸引：

- 普通买家
- 收藏家
- 名人
- 专家
- 竞争对手
- 可疑买家

## 每日经营节奏

每天可以包含多个顾客、若干行动和一次日终结算。

每日流程可以包括：

- 开店
- 接待顾客
- 处理谈判
- 管理库存
- 安排鉴定或修复
- 查看市场波动
- 处理随机事件
- 支付运营成本
- 结算利润和声誉
- 推进游戏日期

时间和行动应成为资源。玩家不能无限制地鉴定、修复和谈判，必须决定当天最值得做的事。

## 胜负与长期成长

游戏可以采用开放式经营目标，也可以设置阶段性目标。

可能的阶段目标：

- 维持经营 30 天。
- 将资金提升到指定金额。
- 完成一次传奇物品交易。
- 升级全部核心设施。
- 建立高声誉当铺。
- 成功识破多次欺诈。
- 偿还全部贷款。

失败条件可以包括：

- 资金长期为负。
- 无法支付租金或税收。
- 声誉过低导致顾客流失。
- 法律事件处理失败。
- 贷款违约。

## AI 模块规划

AI 引擎承担生成、叙事、谈判和事件裁决职责。

核心模块：

- 物品生成系统：生成物品名称、描述、历史、价值、损坏、隐藏属性和鉴定要点。
- 顾客生成系统：生成顾客身份、性格、背景、心理价位、谈判底线和欺诈倾向。
- 自然语言谈判系统：根据玩家输入、顾客性格和游戏状态生成回应并推进谈判。
- 随机事件生成系统：根据经营状态生成事件、选项和后果。
- 鉴定与修复系统：生成鉴定步骤、修复方案、风险和结果。
- 状态裁决系统：将 AI 叙事结果转化为资金、库存、技能、声誉和日期变化。

AI 输出需要尽量结构化，方便后端写入游戏状态，同时保留高质量文本叙事。

顾客和物品生成采用 AI 优先策略。注册、首次建档、重开游戏和进入新一天时，后端会优先等待 AI 生成每日顾客队列；如果没有配置 API Key、接口失败或生成超时，则使用本地模板立即开门，避免玩家被加载流程阻塞。每日 AI 预生成最多等待 30 秒。

## AI 配置

后端通过豆包/火山方舟兼容接口调用大模型。需要在项目根目录 `.env` 或 `backend/.env` 中配置：

```env
DOUBAO_API_KEY=你的 API Key
DOUBAO_API_URL=https://ark.cn-beijing.volces.com/api/v3/chat/completions
DOUBAO_MODEL_ENDPOINT=你的模型 endpoint
```

其中 `DOUBAO_API_KEY` 必填；`DOUBAO_API_URL` 和 `DOUBAO_MODEL_ENDPOINT` 有默认值，可按实际模型服务调整。没有配置 API Key 时，游戏会自动使用本地模板兜底，仍可游玩，但顾客姓名、物品描述和随机事件会更容易重复。

## 界面与交互方向

游戏 UI 应服务文字阅读和经营决策，避免同质化的卡片式堆砌。

设计原则：

- 文字是主角，UI 是背景和引导。
- 功能优先，美学服务体验。
- 通过层次、阴影、渐变、模糊和细分割线创造空间感。
- 避免明显卡片边框、网格卡片布局、过度圆角、鲜艳色块和卡通化图标。
- 保持现代暗黑奢华风与复古当铺质感。

核心布局：

- 顶部导航栏：显示游戏名称、日期、时间、天气、设置、存档和帮助。
- 左侧功能栏：经营导航，例如当铺大厅、库存、展示柜、鉴定室、修复工坊、员工、账本等。
- 中央主内容区：承载对话、事件、物品故事和主要经营操作。
- 右侧信息栏：显示玩家资金、声誉、技能、当铺等级、每日成本和快捷操作。
- 底部输入栏：用于自然语言谈判和玩家指令输入。

视觉基调：

- 主背景色：#0D0F12
- 次级背景色：#14171C
- 强调色：#C8A97E
- 交互色：#D4B88A
- 文本主色：#E0E0E0
- 文本次色：#9E9E9E
- 分割线色：#2A2D34

## 开发注意事项

- 所有经济变化都应能追溯到具体行为或事件。
- AI 生成文本可以丰富，但关键数值必须结构化保存。
- 谈判、鉴定、修复和事件都应更新统一的游戏状态。
- 物品真实价值和顾客心理价位不应完全暴露给玩家。
- 随机事件应服务经营决策，不应只是纯叙事。
- UI 不应削弱文字阅读，装饰元素必须克制。
- 未来新增玩法时，应优先接入核心循环，而不是形成孤立系统。
